对照要点

  • 整块 PanelSection 是深灰卡片，标题小号大写。
  • 状态两行：第一行「自动截图可用/不可用 · 女仆核心 正常/异常」，第二行「设备 IP:端口」。
  • 「截屏询问」是主动作：收面板 → 抓帧 → 带图自动问 AI，忙时变成「中断（Ns）」。
  • 对话紧跟在按钮下方，最高 330px 滚动；所有端的提问与回复都在这里，问答两侧都带来源角标（客户端 / PC网页端 / 手机网页端 / 插件端）。
  • 对话下方才是输入框、「发送」和「带画面询问」开关；再往下是设置项「语音播报回复」，面板到设置为止，不再有「锁定」按钮。
  • 最底部一行是 logo + DeckMeido + 版本号（版本取自后端 /api/config，连不上时显示插件自己的版本）。
  • AI 回复按 markdown 渲染：标题加粗、有序列表缩进 18px、行内码浅底。
